Potential flow

AE2130-I · Delft University of Technology

About

An interactive notebook for second-year aerodynamics. You build up uniform flow, sources, doublets and vortices, see how they combine into the flow around a cylinder and how a vortex creates lift, then run a vortex panel method on a NACA airfoil. Every plot has sliders, and all the maths is plain Python you can read and change.

It runs entirely in your browser, so there is nothing to install. The first run takes a minute while Python loads.
